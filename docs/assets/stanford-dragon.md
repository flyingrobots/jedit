# Stanford Dragon Title Mesh

`src/ui/stanford_dragon_res4.obj` is a format conversion of the Stanford
Dragon reconstruction distributed by the Stanford 3D Scanning Repository.

Source:

- Repository page: https://graphics.stanford.edu/data/3Dscanrep/
- Archive: https://graphics.stanford.edu/pub/3Dscanrep/dragon/dragon_recon.tar.gz
- Source file inside archive: `dragon_recon/dragon_vrip_res4.ply`

Conversion:

- Downloaded on 2026-06-04.
- Converted from ASCII PLY to OBJ without topology changes.
- Vertex count: 5205.
- Triangle count: 11102.
- The OBJ comments preserve the source archive and source file path.

Licensing and provenance posture:

- The Stanford page describes the repository as making range data and
  reconstructed models available to the public.
- The downloaded dragon archive does not include an Apache-2.0 license grant.
- Treat this as a third-party title-screen asset with preserved provenance, not
  as project-authored Apache-2.0 source.
